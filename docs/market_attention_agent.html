回答“市场在关注什么”，并保留判断依据

当前能够提供

从已覆盖渠道中发现金融相关议题，归纳宏观、产业、公司和政策主题，并展示原始新闻链接，帮助读者快速确定后续研究方向。

04 / 从偏好到筛选

一段金融偏好，两阶段模型调用

关注港股、美股市场当前正在讨论的事件和主题，包括宏观经济、货币政策、企业业绩、产业供需、监管政策及资本流动。保留对行业或上市公司有明确关联的科技、地缘政治和政策新闻。排除娱乐八卦、无金融关联的社会新闻、营销内容及缺乏实质信息的讨论。
阶段 A · 提取标签金融偏好＋标签提取模板 → 标签目录模型生成标签名称、范围说明及顺序。程序分配标签 ID 并存储，后续可复用。
→
阶段 B · 判断新闻原始偏好＋标签目录＋新闻 → 分类结果每批最多 200 条；输入新闻标题和来源名称；每条最多保留一个标签及一个分数。

标签提取模板决定分类框架

要求生成 5～20 个标签，标签名称简洁、描述具体、尽量不重叠，并尽量按用户偏好的先后排列。近期产生了港股市场、美股市场、宏观经济、货币政策、企业业绩、产业供需等标签。

原始偏好继续参与逐条判断

分类时再次传入完整金融描述，所以“排除娱乐、营销”等要求没有因为提取标签而丢失。但它们仍是模型需要遵循的语义指令，尚未全部变成独立硬规则。

每条只选一个最相关标签

模型选最相关标签；相关程度接近时，优先选择靠前的标签。新闻可能同时涉及 AI 与港股，但报告只归入其中一个类别。无匹配的新闻按要求不返回。

程序执行阈值和有效性检查

检查新闻 ID、标签 ID 是否来自输入；将分数限制在 0～1；缺失或无法转为数字时按 0.5 处理；重复候选只留最高分；最终仅保留相关度 ≥ 0.7 的记录。

查看一次分类调用的简化示例（分数仅为示意）
输入：
偏好：关注港美股金融事件，排除娱乐与无实质信息的内容。
标签：3. 货币政策 —— 央行利率、加息降息、流动性操作。
新闻：101. [财联社] 美联储宣布下调政策利率

模型返回：
[{"id": 101, "tag_id": 3, "score": 0.95}]

程序判断：
ID 合法，并且 0.95 ≥ 0.7 → 保留。
05 / 分数到底是什么

相关度是模型给出的语义评分

当前模板只明确了 1.0＝完全相关、0.5＝部分相关。模型结合标题、来源名称、标签说明和原始偏好，直接生成分数。代码没有额外使用关键词加权、点击量、向量相似度或模型内部概率来计算相关度。

模型负责判断

新闻和关注主题是否有关？最适合哪个标签？相关程度大约多少？这一判断可能受模型版本、标签范围和标题措辞影响。

程序负责执行

编号是否合法、分数格式是否可用、是否达到 0.7、是否属于当前采集批次，以及是否通过对应时间过滤。

0.8 不表示 80% 的真实性或 80% 的投资价值。
0.7 是当前配置的经验门槛，尚未经过人工标注样本校准。提高门槛通常会减少保留量，但不保证留下的都是重大事件。
容易混淆的概念实际含义当前是否统一计算
相关度标题与金融偏好及分类标签的相关程度。模型输出 0～1，程序以 0.7 过滤。
平台名次对应平台或采样内部的排名。保留原口径，未跨平台归一化。
事件热度同一事件覆盖的平台、讨论规模、持续时间和升温速度。尚无完整事件级聚合评分。
可信度 / 投资意义事实是否可靠，以及对资产的影响。相关度不承担这两项判断。
06 / 为什么可以作为热点分析 Agent

形成“发现 → 筛选 → 归纳 → 可追溯输出”的完整任务流程

它可以定位为一个市场关注热点分析 Agent：任务目标明确，能调用多个信息源、依据偏好筛选内容，再由模型组织分析结果并附上证据。当前实现属于固定流程驱动的分析 Agent，并没有自主扩展调查或自动验证事实的能力。

已有能力

1. 捕捉已显现的关注信号

媒体热榜提供财经议题，社区榜单提供讨论线索，股票人气榜提供标的关注线索。多渠道让观察范围更广。

已有能力

2. 用金融偏好降低噪声

从综合热点中筛出与港美股、宏观、政策和产业有关的标题，使用户不用逐个平台阅读大量无关内容。

已有能力

3. 将散点信息整理成主题

模型把单条标题归纳为核心议题、争议和待核实信号，帮助形成“市场正在谈什么”的阅读提纲。跨平台关联仍是模型归纳，需要核对。

已有能力

4. 为下一步研究提供入口

结论后附来源标签，点击打开原文，悬停查看标题。研究者或下游 Agent 可以据此继续查证和补充正文。

合适的产出：“在本次覆盖的渠道与时间范围内，这些金融话题值得优先阅读。”
合适的下游用途：作为宏观、新闻或热点 Agent 的候选证据入口；涉及评级和资产影响时，应继续抽取事实、校验时间并分析传导关系。

目前总结中的 [[S1]] 等编号由模型引用，程序仅将已登记的输入来源映射为链接。不存在或不安全的引用显示“来源待核实”。这保证链接可追溯，但不能自动证明该来源足以支持每个结论。

07 / 必须明确的边界

当前能发现关注议题，尚不能严格给事件排热度榜

  • 主要看标题：筛选没有逐篇阅读正文，标题缺失的条件、时间和语气可能影响判断。
  • 不是全市场观测：候选池受平台、榜单长度、缓存与富途查询关键词限制；“当前”指本次观察窗口。
  • 跨来源未完全合并事件：多个媒体转载同一消息可能占多条；原始条数不能直接解释为独立证据数量。
  • 单次排名不能证明升温：没有可用历史变化证据时，不应把一次高排名描述成“急升”“资金涌入”或“共识形成”。
  • 宽泛标签可能保留过多股票条目：一只股票上榜容易匹配“港股市场”，但它可能不包含实质新闻事件。
  • 模型总结仍会推断：原模板包含争议、弱信号和策略建议，部分内容可能超过标题证据能支持的范围。
